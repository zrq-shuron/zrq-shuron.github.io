slow-chinese-tools

YouTubeチャンネル「慢慢中文 Slow Chinese」の運営者が、自分のチャンネルを管理するために使う個人用ツールです。 YouTube Data API と YouTube Analytics API を使い、自分のチャンネルの動画の投稿、タイトル・再生リストの更新、再生数の確認を行います。

運営者本人以外の利用は想定していません。

A personal tool used only by the owner of the YouTube channel "慢慢中文 Slow Chinese" to manage that channel (uploading videos, updating titles and playlists, and reading statistics) through the YouTube Data API and YouTube Analytics API.
