プライバシーポリシー

最終更新日：2026年10月21日

slow-chinese-tools（以下「本ツール」）は、YouTubeチャンネル「慢慢中文 Slow Chinese」の運営者が、自分のチャンネルを管理するためだけに使う個人用ツールです。

YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールを使うことで、YouTube 利用規約に同意したことになります。 Google のプライバシーポリシーは https://policies.google.com/privacy を参照してください。

取得する情報

  • 運営者自身のYouTubeチャンネルの情報（動画の一覧、タイトル、説明、再生リスト、再生数などの統計）
  • Googleの認証で発行されるアクセストークン

使い方と保存

  • 取得した情報は、運営者自身のチャンネルの管理（動画の投稿、タイトル・再生リストの更新、統計の確認）にだけ使います
  • 情報とトークンは運営者のPCにだけ保存し、外部のサーバーには送りません
  • 第三者に提供・販売することはありません

アクセスの取り消し

Googleアカウントのセキュリティ設定（サードパーティ アクセス）から、いつでも本ツールのアクセスを取り消せます。取り消すと、保存されているトークンは使えなくなります。

Privacy Policy (English)

Last updated: October 21, 2026

slow-chinese-tools is a personal tool used only by the owner of the YouTube channel "慢慢中文 Slow Chinese" to manage that channel.

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See the Google Privacy Policy.

It accesses only the owner's own channel data (videos, titles, descriptions, playlists, statistics) and OAuth tokens. Data and tokens are stored only on the owner's computer, are used only to manage the owner's channel, and are never shared with or sold to third parties. Access can be revoked at any time at https://myaccount.google.com/permissions.
